# Critique

Run this draft through THE GATE. Be blunt. Vague praise costs me money.

**The draft:**
```
[PASTE]
```

**Do this, in order:**

**1. THE GATE** — the six checks from `03-OPERATING-SYSTEM.md`. PASS or FAIL each,
one line of evidence for each:
- One argument
- A position, not a topic
- A receipt
- In voice
- Fresh angle
- No landmines

**2. The hook** — against the seven-point checklist in `04-HOOK-GUIDE.md` Part 7.
Character count it.

**3. Style** — against `07-WRITING-STYLE.md`. Quote every:
- banned word or phrase
- vague claim that should be specific
- rounded number
- hedge
- AI tell

**4. Structure** — which format is this trying to be? Is it succeeding? Where does
attention drop?

**5. Length** — character count. Line count. Against the targets in
`06-POST-STRUCTURE.md`.

**6. Media** — what should be attached? Is it the right type for this format?

**Then give me the verdict, in this shape:**

```
VERDICT: SHIP / FIX / KILL

If FIX — the three changes, in priority order, each with the rewritten line.
If KILL — why, and whether any part is worth keeping for something else.

THE ONE LINE I'D CUT: [quote it]
THE ONE LINE I'D KEEP: [quote it] — this is what the post is actually about
WHAT'S MISSING: the single thing that would most improve it
```

Do not soften the verdict. If it is generic, say it is generic. If a competitor
could have written it, say so.
