# Prompts

Copy the contents of any file below into a chat inside your configured Project.
They assume the Project already has every file from this pack in its knowledge and
`01-PROJECT-INSTRUCTIONS.md` in its custom instructions.

| Prompt | Use it when |
|---|---|
| `draft-post.md` | You have raw material and need a finished post |
| `hook-lab.md` | You have a post and the opening is not working |
| `critique.md` | You have a draft and want a blunt second opinion |
| `interview.md` | You have a call transcript and need to extract what's usable |
| `carousel.md` | You have a post that should be a carousel |
| `repurpose.md` | You have one good post and want four more things from it |
| `self-audit.md` | You have an analytics export and want to know what actually works |
| `voice-bible.md` | You want to build a voice guide for a specific person from their real posts |

**The one that matters most is `voice-bible.md`.** Run it once per person you write
for. It is what stops everything sounding like a generic assistant, and it is the
difference between this pack working and this pack being a nice PDF.
