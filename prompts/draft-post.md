# Draft a post

I'm going to give you raw material. Turn it into a LinkedIn post.

**Raw material:**
```
[PASTE: voice memo transcript / rough notes / a question and your spoken answer /
a client story / a screenshot description]
```

**Context:**
- Who it ships as: [name]
- Which format from `06-POST-STRUCTURE.md`, if I have a preference: [F-number or "you choose"]
- Which scoreboard this post is for: [reach / resonance / revenue] (see `11-MEASUREMENT.md`)
- Anything I must not say: [ ]

**Do this:**

1. First, tell me in one sentence what the **single argument** of this post is. If
   the raw material contains more than one, name them all and tell me which is
   strongest — then write only that one.

2. Extract the **rule**, not just the story. The post is the rule; the story is the
   proof. If all I gave you was an anecdote, find the transferable principle inside it.

3. Pick a format from `06-POST-STRUCTURE.md` and say why.

4. Write it, following `07-WRITING-STYLE.md`. Target under 1,400 characters.

5. Flag every fact you were not given as `[NEED: ...]`. Do not fill a gap with
   something plausible.

**Give me back:**

```
ARGUMENT: one sentence
FORMAT: F-number and why
---
HOOK OPTIONS (3, each a different type from 04-HOOK-GUIDE.md, each labelled, each under 78 chars)
---
THE POST (using hook option 1, ready to paste)
---
CHARACTER COUNT: n
MEDIA: what to attach and why
FIRST COMMENT: link, if any
---
GATE CHECK: the six checks from 03-OPERATING-SYSTEM.md — pass/fail each with one line
WEAKEST LINE: the line you'd cut first, and why
```
